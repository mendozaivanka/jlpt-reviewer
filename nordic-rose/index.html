Design system · source on GitHub

Nordic Rose

Calm interfaces for careful work: cool greys, soft corners, one pastel pink for action and a single typeface.

This is the system the rest of the site is built with. It documents the tokens, the type, every shadcn/ui component in use, and the contrast numbers, which are computed from the same token file that generates the CSS.

Principles

  1. 01

    Calm first

    Cool greys, soft corners and plenty of air. One clear point of focus per screen; everything else recedes.

  2. 02

    Rosas for action

    One pastel pink, used for the thing you should press, always with dark text. Deep rose carries links and emphasis.

  3. 03

    One warm colour

    Pink is the only warm hue. Fjord blue-grey is the second colour, for secondary links and annotations.

  4. 04

    Quiet categories

    Moss, sand and heather tint badges and chart categories. They never carry text colour themselves.

  5. 05

    One typeface

    Manrope for headings and body, set tighter and heavier for headings; Red Hat Mono for labels and numbers.

  6. 06

    Accessible by default

    4.5:1 for text and 3:1 for controls in every theme, checked at build time; high contrast built in.

How it's built

  1. 01

    Tokens in TypeScript

    src/data/tokens.ts holds every colour for four themes. A script generates tokens.css from it before each build, and this page reads the same file.

  2. 02

    Tailwind CSS v4 + shadcn/ui

    shadcn's CSS-variable theme (radix-nova preset) maps straight onto the tokens, so every component picks up Nordic Rose with no overrides.

  3. 03

    All shadcn/ui components

    Button, Card, Badge, Tabs, Dropdown Menu, Command, Dialog, Select, Switch, Toggle Group, Table, Kbd, Avatar, Separator, Sonner: added with the CLI, versioned in src/components/ui.

  4. 04

    Astro islands

    Pages are static HTML; only the interactive parts ship React (client:load / idle / visible).

  5. 05

    Checks on every build

    astro check for types, and the contrast table above, which throws if any pair drops below target.

  6. 06

    Static hosting

    Plain static files, so any free static host works (Render, Netlify, Cloudflare Pages, GitHub Pages).
